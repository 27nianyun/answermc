# 2026-10-04 工作日志

## 新玩法提案前的数据资产探查

用户问「还有什么新玩法」。为避免空想，先把现有数据能撑起什么摸清楚。
以下数字是实测出来的，后续做任何玩法都能直接引用，不必重算。

### catalog.json（2827 条）

**数值属性覆盖率**（决定「属性对决 / 排序」类玩法能不能出题）：
```
堆叠上限 2672
硬度     1167
爆炸抗性 1167
发光等级 1167
遮光等级 1167
碰撞宽度  155
碰撞高度  155
```
方块类条目普遍带硬度/抗性/发光/遮光四个数值，物品类多只有堆叠上限。
→ 属性比较类玩法题量充足，但**只有 1167 条能比硬度**，别按 2827 估算。

**分类**：`family` 共 41 个，最大的是「常规物品 790 / 建筑方块 563 / 台阶 124 / 楼梯 116 / 墙 112」。
→ 「找异类 / 归类」类玩法可用，但头部几个 family 很大，出题要防止一组里全是同族导致太简单。

### transformations.json（1096 条）

- 顶层字段是 `transforms`（不是 transformations）
- `method` 共 11 种：craft_shaped 459 / stonecut 275 / craft_shapeless 97 /
  smelt 70 / wax 60 / scrape 60 / strip 23 / blast 22 / smith 12 / campfire 9 / smoke 9
- `layout` 5 种：grid-shaped 459 / single 358 / grid-shapeless 97 / furnace 110 / dual 72
- `dual` 是「两格输入」型（如锻造台：钻石斧 + 下界合金锭 → 下界合金斧）

**反查（产物 → 做法）**：
- 730 个不同产物
- **206 个产物有多种做法**（金锭 9 种、铜锭 7 种、铁锭 7 种、深板岩砖台阶 6 种）
- 配方网络涉及 924 个物品，其中 730 可合成、194 是基础原料

→ **「逆向合成」玩法完全成立**，而且多解特性正好能考等价替换（`tag` 字段，
  如 `minecraft:netherite_tool_materials`），与用户此前要求的「煤炭木炭互换」是同一套机制。

⚠️ 未验证：想做「最短工序链 / 速通合成」时我写的递归深度函数有 bug
（piston / observer 返回环检测值 99，而 diamond_pickaxe 返回 0 —— 后者不该是 0）。
**做这类玩法前必须先修好这个探查函数并重新验证合成图是否有环**，不要直接相信上面的深度结论。

### 提议的四个新玩法（按推荐顺序）

1. **属性对决**（二选一猜谁更高）— 全新认知维度，现有玩法都在考「识别」，
   这个考「量级直觉」；1167 条支撑，成本最低
2. **逆向合成**（给产物倒推原料）— 复用 transformations 的另一半，730 产物 / 206 多解
3. **找异类**（四个里挑不合群的）— 41 个 family，实现关键是**保证分组唯一**
   （否则玩家能找出第二种合理分法，体验崩坏）
4. **每日挑战**（固定种子 + 成绩分享）— 留存机制，不是新玩法本身而是放大器

### 明确不建议

- 盲猜音效：项目没有音效资源
- 结构还原（摆地狱门 / 铁傀儡）：和现有「合成配方」都是网格摆放，重复度高且要新数据
